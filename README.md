# ForestWarbler in the Afterglow
My personal website (mostly for academic purpose).

### Local Preview

Run this command from the repository directory:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [the local homepage](http://127.0.0.1:8000/index.html). The site loads JSON content and should be previewed over HTTP.
